# TaskFlow

Vue 3 + Vite приложение для ведения рабочих задач и сбора данных для аналитики производительности. Основное хранилище - Supabase, локальный cache используется для быстрого интерфейса и одноразовой миграции старых данных.

## Данные задачи

TaskFlow сохраняет задачи, действия, рабочие сессии, паузы и настройки в Supabase. Локальный cache повторяет нормализованные данные для синхронной работы существующего UI.

## Учёт работы

- Новая задача создаётся в статусе `К выполнению`.
- Одновременно в статусе `В работе` может быть только одна задача.
- На Dashboard доступны только те типы, которые были выбраны при создании задачи.
- Выбор типа запускает рабочую сессию. Переключение типа автоматически закрывает предыдущую сессию и открывает новую.
- Переключение `Дом / Офис` во время работы также разделяет сессию, чтобы аналитика могла сравнивать локации.
- Статусы `Приостановлена` и `Готово` закрывают активную сессию.
- При `Готово` сохраняется `completedAt`.
- Каждое добавленное действие хранит тип, операцию, ссылку, время, локацию и идентификатор рабочей сессии. На Dashboard действия показываются от новых к старым, по 20 строк на страницу; ссылку можно отредактировать, действие можно удалить.

## Запуск

```bash
npm install
npm run dev
```

## Паузы

На Dashboard активный рабочий таймер можно поставить на паузу с причиной `Перерыв`, `Обед` или `Личное`. Пауза закрывает текущую рабочую сессию, но не меняет статус задачи `В работе`. После `Продолжить` создаётся новая рабочая сессия с тем же рабочим контекстом. Время пауз не входит в фактическое рабочее время.

## Аналитика

Страница `/analytics` строится по синхронизированным данным Supabase. Доступны периоды `Сегодня`, `7 дней`, `30 дней`, текущий/прошлый месяц, всё время и произвольный диапазон. Фильтры: тип, место, действие, категория и статус. Рассчитываются завершённые задачи, output, фактическое рабочее время, output/hour, план/факт, динамика, Дом/Офис, дневной минимум, статистика по типам, операциям и категориям.

## Отчёты

Страница `/reports` формирует отчёт для руководителя. Основная таблица группирует результат по типам работы и показывает количество созданий, добавлений и редактирований, общий output, фактическое время, скорость работы и раскрываемый список ссылок-доказательств. Отчёт можно отфильтровать по периоду, типу, категории и месту, отсортировать, скопировать, выгрузить в CSV или распечатать/сохранить в PDF.

## Настройки

Страница `/settings` хранит рабочий график и категории. По умолчанию: понедельник и среда — офис, вторник, четверг и пятница — дом, суббота и воскресенье — выходные. Dashboard автоматически подставляет место работы по дню недели, при этом ручное переключение сохраняется как переопределение только для текущего дня. Категории создаются в Settings и затем выбираются из списка в форме задачи.

## Графики

Интерактивный график Analytics работает через ApexCharts, подключённый в `index.html`. При наведении отображаются точные значения по точкам периода.


## Read-only страница руководителя

В Settings создаётся постоянный токен-маршрут `/manager/:token`. На этой странице нет Sidebar и переходов в приватный TaskFlow. Руководитель видит текущую задачу, место работы по расписанию, количество выполненных единиц, прогресс по плану, средний результат по похожим задачам, динамику output, сводку по типам, завершённые задачи и прямые ссылки-доказательства. Рабочие сессии, длительность работы и паузы в публичный payload не попадают.

Публичная manager-ссылка работает через Supabase RPC и доступна с любого устройства без входа. Токен хранится в базе только в виде SHA-256 хэша.

## Supabase

Подключение активно. В `.env` используются `VITE_SUPABASE_URL` и `VITE_SUPABASE_PUBLISHABLE_KEY`. Приватные страницы требуют входа через Supabase Auth. При первом входе существующие локальные задачи автоматически переносятся в таблицы Supabase, если база пользователя ещё пустая.

Если старая схема v1.4.0 уже была запущена, выполните `supabase/migration_v1.5.sql`. Для нового проекта можно выполнить полный `supabase/schema.sql`.

Публичная страница руководителя получает только sanitized payload через `taskflow_manager_snapshot`: задачи, output и ссылки-доказательства. Work sessions, breaks и плановые минуты RPC не возвращает.

## Графики

ApexCharts подключён в `index.html` и используется в Analytics и read-only странице руководителя.
